WEBSITES PAGE UPDATE

Upload to your existing Websites repository on GitHub.

1. Unzip Websites-Update.zip.
2. Open your Websites repository, then select Add file > Upload files.
3. Drag index.html and the three folders (previews, media, portfolio)
   into the upload area. Keep these folder names and their contents intact.
   index.html must be at the top level, not inside an extra Websites-Update folder.
4. Commit the changes. Your existing GitHub Pages settings can stay the same.
5. After GitHub finishes deploying, reload your Websites page.

You can upload README.txt too, or leave it on your computer.
Upload the unzipped contents, not the ZIP itself.
